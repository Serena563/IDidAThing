# I did a thing!

Tik aan wat je deed. Rust telt ook. Wat je in Huisritme afvinkt komt er vanzelf bij (via Dropbox).

Versie 2026-10-27a

## Online zetten (eenmalig)
1. Maak op GitHub (account Serena563) een nieuwe repository met de naam `i-did-a-thing`.
2. Upload `index.html`, `README.md` en `.nojekyll`.
3. Settings → Pages → Branch: `main`, map `/ (root)` → Save.
4. De app staat daarna op https://serena563.github.io/i-did-a-thing/

## Dropbox (eenmalig)
De app gebruikt dezelfde Dropbox-app als Huisritme (app key k2a2fputgkhil79).
Daardoor kan hij je afgevinkte Huisritme-taken lezen.

1. Ga naar dropbox.com/developers/apps en open de Huisritme-app.
2. Tabblad Settings → Redirect URIs → voeg toe: `https://serena563.github.io/i-did-a-thing/` (met de schuine streep aan het eind) → Add.
3. Open de app, ga naar Knoppen en tik op "Koppel Dropbox".

Je gegevens staan in je Dropbox in Apps/(Huisritme-app)/i-did-a-thing.json.
